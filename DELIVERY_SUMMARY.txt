PROJECT OVERVIEW
================================================================================
Complete Python pipeline for creating YOLO training datasets for building 
detection from GeoBizkaia geospatial data (geopackages + ArcGIS imagery).

QUICK START
================================================================================

1. Install dependencies:
   pip install -r requirements_yolo.txt

2. Identify layer names in your geopackages:
   cd src/geobizkaia
   python inspect_gpkg.py ../../data/vector/extents/extent.gpkg
   python inspect_gpkg.py ../../data/vector/carto/karto.gpkg

3. Update layer names if needed in run_yolo_pipeline.py

4. Test with 3 extents:
   python run_yolo_pipeline.py --test

5. Process full dataset:
   python run_yolo_pipeline.py --full

YOLO FORMAT
================================================================================

Each building annotation:
<class_id> <x_center> <y_center> <width> <height>

All values normalized to [0,1]:
- class_id: 0 (buildings)
- x_center, y_center: normalized center coordinates
- width, height: normalized dimensions

Example annotation file:
0 0.512 0.623 0.128 0.156
0 0.784 0.445 0.095 0.112
0 0.234 0.567 0.089 0.102

COMMAND EXAMPLES
================================================================================

# Test mode (3 extents, no splitting)
python run_yolo_pipeline.py --test

# Full processing
python run_yolo_pipeline.py --full

# Custom: 10 extents with 80/10/10 split
python run_yolo_pipeline.py --limit 10 --split --train-ratio 0.8 --val-ratio 0.1

# Custom image size
python run_yolo_pipeline.py --full --image-size 2048

# Custom layer names
python run_yolo_pipeline.py --full --extents-layer my_extent --buildings-layer my_buildings

# Get help
python run_yolo_pipeline.py --help

TRAINING WITH YOLOV8
================================================================================

After generating the dataset, train with YOLOv8:

from ultralytics import YOLO

model = YOLO('yolov8n.pt')  # nano/small/medium/large/xlarge

results = model.train(
    data='dataset/yolo_buildings/data.yaml',
    epochs=100,
    imgsz=4096,
    device=0,
    patience=20,
    save=True,
    name='buildings_detection'
)

TROUBLESHOOTING
================================================================================

Issue: Layer not found
→ Run inspect_gpkg.py to see available layers

Issue: No buildings found
→ Check CRS alignment and extent boundaries

Issue: Download failures
→ Verify internet connection and ArcGIS URL

Issue: Memory issues
→ Use --limit or reduce --image-size

Issue: Missing annotations
→ Check if buildings actually intersect extents

KEY CONFIGURATION
================================================================================

Default Settings:
- Image size: 4096×4096 pixels
- CRS: EPSG:3857 (Web Mercator)
- Train/Val/Test split: 70%/15%/15%
- ArcGIS MapServer: GeoBizkaia ORTO_EJ_2024

Customizable:
- Image size (--image-size)
- Layer names (--extents-layer, --buildings-layer)
- Split ratios (--train-ratio, --val-ratio)
- Extent limit (--limit)
- Imagery URL (--imagery-url)
