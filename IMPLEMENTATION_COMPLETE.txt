================================================================================
KEY DIFFERENCES: Detection vs Segmentation
================================================================================

DETECTION (Original):
  - Output: Bounding boxes (4 values per object)
  - Annotation Format: .txt files with normalized coordinates
  - Model: YOLOv8 (detect)
  - Task: Find object location and size
  - Files: dataset/yolo_buildings/labels/*.txt

SEGMENTATION (New):
  - Output: Pixel-level masks (0/255 binary)
  - Annotation Format: .png binary images
  - Model: YOLOv8-Seg (segment)
  - Task: Classify every pixel as building or background
  - Files: dataset/yolo_buildings_seg/masks/*.png

================================================================================
QUICK START GUIDE
================================================================================

Step 1: Generate Segmentation Dataset
  python run_segmentation_pipeline.py --test
  
  Options:
    --test              Process 3 test extents
    --full              Process all extents (with train/val/test split)
    --limit N           Process N extents
    --split             Create train/val/test split
    --image-size SIZE   Download image size (default: 4096)
    --no-vector-clipping Skip FeatureServer queries

Step 2: Train Segmentation Model
  python train_segmentation_model.py --model n --epochs 100 --imgsz 4096
  
  Options:
    --model {n,s,m,l,x}  Model size: nano, small, medium, large, xlarge
    --epochs N           Training epochs (default: 100)
    --batch N            Batch size (default: 4)
    --imgsz SIZE         Input image size (default: 640)
    --device ID          GPU device (default: 0)
    --patience N         Early stopping patience
    --validate-only      Skip training, run validation only
    --test-only PATH     Skip training, run test inference only

Step 3: Check Results
  - Model saved to: model/best_yolov8{n,s,m,l,x}-seg.pt
  - Training history: model/training_history_yolov8{n,s,m,l,x}-seg.json
  - Training log: training_seg.log
  - Validation metrics printed after training

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

For common issues:
  1. Check SEGMENTATION_GUIDE.md "Troubleshooting" section
  2. Review training logs: tail -f training_seg.log
  3. Verify GeoPackage data: python inspect_gpkg.py
  4. Test with small dataset first: --limit 3

Memory Issues?
  - Reduce batch size: --batch 2
  - Reduce image size: --imgsz 1024
  - Use smaller model: --model n

Training Too Slow?
  - Use smaller model: --model n or --model s
