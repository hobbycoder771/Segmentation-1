❓ COMMON QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q: What layer names should I use?
A: Run inspect_gpkg.py to see what's in your geopackages.
   Most people don't need to change the defaults.

Q: Can I test with fewer extents?
A: Yes! Use: python run_yolo_pipeline.py --limit 5 --split

Q: How long does full processing take?
A: Depends on extent count and internet speed.
   Typically 10-30 seconds per extent.

Q: What if I get a "Layer not found" error?
A: Run inspect_gpkg.py to see actual layer names.
   Update the layer name in run_yolo_pipeline.py or CLI args.

Q: Can I change the train/val/test split?
A: Yes! Use: --train-ratio 0.8 --val-ratio 0.1

Q: What's the output format?
A: YOLO format with:
   - GeoTIFF images (4096×4096 pixels)
   - Text annotations (normalized bounding boxes)
   - data.yaml for YOLOv8 training

Q: How do I train a YOLO model?
A: Use dataset/yolo_buildings/data.yaml with YOLOv8:
   from ultralytics import YOLO
   model = YOLO('yolov8n.pt')
   model.train(data='dataset/yolo_buildings/data.yaml', epochs=100)

📞 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Error: "Layer not found"
→ Run: python inspect_gpkg.py <your_gpkg_file>
→ Update layer names in configuration

Error: "No buildings found"
→ Check if buildings actually intersect with extents
→ Verify CRS is same (EPSG:3857)

Error: Download failures
→ Check internet connection
→ Verify ArcGIS URL is accessible
→ Try manual download to debug

Memory issues
→ Use: --image-size 2048 (smaller images)
→ Use: --limit 10 (process fewer extents)

For more help:
→ Read YOLO_SETUP_GUIDE.md (troubleshooting section)
→ Read USAGE_FLOW.txt (workflow diagram)
