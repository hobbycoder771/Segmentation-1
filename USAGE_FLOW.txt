INPUT DATA:
┌────────────────────────────────────────────────────────────────┐
│ GeoPackage Files (EPSG:3857 coordinates)                       │
│                                                                 │
│ 1. Extents (e.g., 1km × 1km tiles)                            │
│    └─ Geometry: Polygons                                       │
│                                                                 │
│ 2. Buildings (e.g., building footprints)                       │
│    └─ Geometry: Polygons or Multipolygons                      │
└────────────────────────────────────────────────────────────────┘
                            ↓
                    [yolo_data_builder.py]
                            ↓
PROCESSING STEPS:
1. Load extents and buildings from GeoPackage
2. For each extent:
   a) Download 4096×4096 imagery from ArcGIS MapServer
   b) Convert PNG to georeferenced GeoTIFF
   c) Find all buildings intersecting this extent
   d) For each building:
      - Get bounding box in map coordinates (meters)
      - Transform to pixel coordinates
      - Normalize to [0,1] range
      - Write as YOLO format: "0 x_center y_center width height"
3. Split images/labels into train/val/test directories
4. Generate data.yaml for YOLOv8
                            ↓
OUTPUT DATA:
┌────────────────────────────────────────────────────────────────┐
│ YOLO Training Dataset                                          │
│                                                                 │
│ Images/
│  ├── train/        (extent_0000.tif, extent_0001.tif, ...)   │
│  ├── val/          (extent_1234.tif, extent_1235.tif, ...)   │
│  └── test/         (extent_5678.tif, extent_5679.tif, ...)   │
│                                                                 │
│ Labels/
│  ├── train/        (extent_0000.txt, extent_0001.txt, ...)   │
│  ├── val/          (extent_1234.txt, extent_1235.txt, ...)   │
│  └── test/         (extent_5678.txt, extent_5679.txt, ...)   │
│                                                                 │
│ data.yaml          (YOLO configuration)                        │
└────────────────────────────────────────────────────────────────┘

ANNOTATION FORMAT EXAMPLE (labels/train/extent_0000.txt):
  0 0.512 0.623 0.128 0.156  ← Building 1
  0 0.784 0.445 0.095 0.112  ← Building 2
  0 0.234 0.567 0.089 0.102  ← Building 3
  
  Format: class_id x_center y_center width height (all normalized 0-1)

Problem: "Layer not found" error
Solution: 
  1. Run: python inspect_gpkg.py <your_gpkg_path>
  2. Note the exact layer name shown
  3. Update configuration with correct name
  4. Retry

Problem: "No buildings found in extent"
Solution:
  1. Verify buildings and extents have same CRS
  2. Check that buildings actually intersect with extents
  3. Visualize both layers to confirm overlap
  4. Try with first few extents manually

Problem: Download failures
Solution:
  1. Check internet connection
  2. Verify ArcGIS MapServer URL is accessible
  3. Try downloading one tile manually
  4. Check firewall/proxy settings

Problem: Memory issues
Solution:
  1. Reduce image size: --image-size 2048
  2. Process fewer extents: --limit 10
  3. Close other applications
  4. Increase system RAM if persistent

Problem: Empty annotations (no buildings detected)
Solution:
  1. Verify buildings data exists in GeoPackage
  2. Check CRS alignment with: inspect_gpkg.py
  3. Visualize extent + buildings to confirm overlap
  4. Check if building layer name is correct
